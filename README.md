# ICE-study

- 사이트: https://sumilee-phd.github.io/ICE-study/
- 기준일: 2026-11-21

## 공개 원칙

- 싣는 것: 출제기준 항목, 법령 조문(저작권법 제7조에 따라 보호 대상이 아닌 저작물), 직접 작성한 정리·문제·공식.
- 싣지 않는 것: 기출 문제 원문, 수험서·강의 내용. 기출 풀이는 원 사이트로 연결합니다.
- 공식 자료가 아니며 오류가 있을 수 있습니다. 시험 전에는 반드시 원문을 확인하십시오.
