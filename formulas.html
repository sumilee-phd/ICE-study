홈 출제기준 점검표 헷갈리는 개념 법규 퀴즈 공식 카드 자료 링크

공식 카드

출제기준의 계산 항목(신호의 dB 크기, 실효값·평균값, 채널용량, 변조, 광케이블 측정, 트래픽·용량 산정 등)에 쓰는 공식입니다. log는 상용로그(밑 10)입니다.

신호 크기

데시벨

전력비 [dB] = 10 log(P2 / P1) 전압비 [dB] = 20 log(V2 / V1)

전력 2배 ≈ +3dB, 10배 = +10dB, 1/2 ≈ −3dB. 전압 2배 ≈ +6dB.

절대 레벨

dBm = 10 log(P / 1mW) dBW = 10 log(P / 1W) = dBm − 30

0dBm = 1mW, 10dBm = 10mW, 30dBm = 1W, −30dBm = 1μW.

실효값·평균값(정현파)

Vrms = Vm / √2 ≈ 0.707 Vm Vavg = 2Vm / π ≈ 0.637 Vm (반주기 평균) 파고율 = Vm / Vrms = √2 ≈ 1.414 파형률 = Vrms / Vavg ≈ 1.11

신호대잡음비

S/N [dB] = 10 log(S / N) (전력)

S/N 30dB = 전력비 1,000배.

전송로

파장과 전파 속도

λ = v / f, 자유공간 v = c = 3 × 10⁸ m/s 매질 속 v = c / n

광섬유(n ≈ 1.5) 속 약 2 × 10⁸ m/s. 300MHz의 파장은 1m.

특성 임피던스

Z0 = √((R + jωL) / (G + jωC)) 무손실 선로: Z0 = √(L / C)

반사계수·정재파비

Γ = (ZL − Z0) / (ZL + Z0) VSWR = (1 + |Γ|) / (1 − |Γ|) 반사손실 [dB] = −20 log|Γ|

정합(ZL = Z0)이면 Γ = 0, VSWR = 1.

광섬유 개구수

NA = √(n1² − n2²) = sin θmax

n1: 코어 굴절률, n2: 클래드 굴절률.

채널용량·디지털 전송

샤논 채널용량

C = B log₂(1 + S/N) [bps]

S/N은 dB가 아닌 전력비로 넣습니다.

나이퀴스트(잡음 없음)

C = 2B log₂ M [bps] 보오율 [baud] = 비트율 / log₂ M

M: 신호 레벨(심볼) 수. QPSK는 심볼당 2비트, 16QAM은 4비트.

PCM

fs ≥ 2 fm 전화: fs = 8kHz, 8비트 → 64kbps, 표본 간격 125μs S/Nq ≈ 6.02 n + 1.76 [dB]

양자화 계단 수 = 2ⁿ. 1비트 늘리면 약 6dB 개선.

가용도·신뢰도

가용도 A = MTBF / (MTBF + MTTR)

MTBF: 평균 고장 간격, MTTR: 평균 수리 시간, MTTF: 평균 고장 시간(수리 불가 장비).

아날로그 변조

AM

변조도 m = Vm / Vc (0 ≤ m ≤ 1) Pt = Pc (1 + m² / 2) 대역폭: DSB = 2fm, SSB = fm

m = 1이면 Pt = 1.5Pc, 측파대 전력은 전체의 1/3. m > 1은 과변조.

FM

β = Δf / fm 카슨 대역폭 B = 2(Δf + fm)

FM 방송: Δf = 75kHz, fm = 15kHz → β = 5, B = 180kHz(채널 간격 200kHz).

광케이블 측정

광 링크 손실 예산

총손실 [dB] = α × L + 접속손실 × 접속점 수 + 커넥터손실 × 커넥터 수 수신 전력 [dBm] = 송신 전력 [dBm] − 총손실 [dB] 시스템 여유 [dB] = 수신 전력 − 수신 감도

α: 광섬유 손실 [dB/km], L: 길이 [km].

OTDR(후방산란법) 손실

α = (5 / L) log(P1 / P2) [dB/km]

빛이 왕복하므로 10 log를 2로 나눈 꼴입니다. P1·P2: 두 지점의 후방산란광 세기, L: 두 지점 사이 거리.

트래픽·용량 산정(실기)

호량(트래픽)

A [Erl] = 호 수 × 평균 보류시간 / 측정 시간 = 시간당 호 수 × 평균 보류시간[h]

1Erl은 회선 하나를 1시간 내내 점유한 양입니다. 필요한 회선 수는 호손율 표(얼랑 B)로 구합니다.
